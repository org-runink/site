{{/* Scoped styles for the Industries section. Deliberately inlined rather than added to assets/css/main.css. The site has two CSS paths — the PostCSS pipeline over assets/css/main.css (what CI builds) and the pre-compiled static/css/style.css used when params.disablePostCSS is true, which is generated from the THEME's main.css and would never see a rule added to ours. WHY THE SECTION IS LIGHT. The review of the customer-facing material said the black canvas makes the information hard to read and painful to print, and that these pages should be visual and easy to skim. So the industry pages are set on a near-white canvas with one deep navy band, and the whole page is built out of ruled lines: a measure is a label and a line you write on. The site header above stays dark, so the page still sits inside the site. Every colour is a DESIGN.md token: canvas/sheet/rule surface.gray_50 / white / gray_200 tint/deep/deep-2 primary.50 / primary.900 / primary.700 ink/ink-2 text.gray_900 / text.gray_600 accent per-page, from front matter The per-industry accent arrives as --accent on the wrapper. Two of the five accents are pale (light sage, tan) and would vanish on a white sheet, so nothing that has to be legible uses the raw accent: --accent-ink mixes it toward primary.900, which keeps every industry distinguishable while holding a contrast ratio comfortably past 4.5:1 on white whatever the accent is. Rules that use color-mix() declare a flat fallback first, so a browser without color-mix() keeps a legible navy rather than dropping the declaration. The print rules at the foot are global on purpose. This partial only ships on industry pages, so hiding the fixed site header there cannot affect any other page — and a fixed header reprinted on every sheet is exactly what the review complained about. Type is Inter and Plus Jakarta Sans, already loaded site-wide. Nothing here adds a request. */}}
