{{/* Scoped styles for the Industries section. Deliberately inlined rather than added to assets/css/main.css. The site has two CSS paths — the PostCSS pipeline over assets/css/main.css (what CI builds) and the pre-compiled static/css/style.css used when params.disablePostCSS is true, which is generated from the THEME's main.css and would never see a rule added to ours. Inlining is the only place both paths agree. Every colour is a DESIGN.md token.
