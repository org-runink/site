{{- /* Positional arg 5 is the CTA href, and it used to go straight through `relURL`. relURL resolves a relative path against the site root but does NOT reject a scheme or a protocol-relative URL, so "//evil.com" came out the other side as a working off-site link. (A "javascript:" scheme was already inert -- html/template rewrites an unsafe URL to "#ZgotmplZ" before it reaches the page -- so this is about off-site links and about not shipping ZgotmplZ into the RSS feed, not about script execution.) Allow exactly what a CTA legitimately needs: an http(s) URL, a mailto:, or a site-relative path. Anything else becomes "#". Fixtures for every branch below live in content/tests/ (drafts, never published). */ -}} {{- $raw := trim (.Get 5) " \t\r\n" -}} {{- $lower := lower $raw -}} {{- $href := "#" -}} {{- if hasPrefix $raw "//" -}} {{- /* protocol-relative: off-site, and relURL leaves it intact */ -}} {{- else if findRE `[[:cntrl:]\\]` $raw -}} {{- /* A backslash or a control character. Hugo does NOT expand Go escapes in a quoted shortcode argument, so `"\tjavascript:alert(1)"` arrives as a literal backslash + "t" + the scheme -- which slips past a scheme test but is still not a link anyone meant to write. No legitimate href needs either character before URL-encoding. */ -}} {{- else if or (hasPrefix $lower "http://") (hasPrefix $lower "https://") (hasPrefix $lower "mailto:") -}} {{- $href = $raw -}} {{- else if findRE `^[a-zA-Z][a-zA-Z0-9+.\-]*:` $raw -}} {{- /* any other scheme: javascript:, data:, vbscript:, file: ... */ -}} {{- else -}} {{- $href = $raw | relURL -}} {{- end -}}
